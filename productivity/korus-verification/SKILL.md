# KORUS 교육훈련 실적 검증 워크플로우

이 스킬은 KORUS에서 내려받은 교육훈련 실적 엑셀 파일과 증빙 폴더 내의 파일들을 대조하여 승인 추천 여부를 판단하는 엄격한 검증 절차를 정의합니다.

## 🛠 필수 제약 조건
- **입력(IN) 폴더**: `D:\dev\hermes\pr01\IN\` (읽기 전용. 수정/이동/삭제 절대 금지)
- **출력(OUT) 폴더**: `D:\dev\hermes\pr01\OUT\` (모든 결과물 저장소)
- **개인정보 보호**: 실명/교번 포함 데이터는 온프레미스 모델만 사용. 외부 전송 금지.
- **자동화 제한**: KORUS 시스템의 '일괄반영' 버튼을 직접 누르지 않음. 오직 '순번 목록'만 제공함.

## 📋 검증 파이프라인

### 단계 0: 사용자 준비사항 안내 (Guidance)
실제 검증을 시작하기 전, 반드시 다음 준비사항을 사용자에게 안내하고 확인받는다.

**[준비사항 안내 메시지]**
1. **데이터 파일 배치**: `D:\dev\hermes\pr01\IN\` 폴더에 KORUS에서 내려받은 **실적 엑셀 파일(.xls)** 1개를 넣어주세요.
2. **파일명 및 중복 관리**: 폴더 내에 분석 대상 외의 다른 `.xls` 파일이 있으면 잘못된 파일이 읽힐 수 있습니다. 대상 파일 외의 엑셀 파일은 다른 폴더로 이동시켜 주세요.
3. **증빙 파일 위치**: 모든 증빙 파일은 반드시 `D:\dev\hermes\pr01\IN\증빙\` 폴더 안에 위치해야 합니다.
4. **결과 확인 경로**: 모든 작업이 완료되면 `D:\dev\hermes\pr01\OUT\` 폴더에서 다음 파일을 확인하세요.

   - `final_results.xlsx`: 판정, 확신도, 사유가 포함된 상세 엑셀 결과
   - `checkbox_list.txt`: KORUS 화면에서 즉시 체크할 승인 추천 순번 목록

### 단계 1: Preflight (정합성 점검)
검증 시작 전, 다음 조건이 모두 충족되어야 한다. 하나라도 실패 시 전체 중단 후 보고한다.
- **P1**: 증빙 있는 행 수 == 폴더 내 파일 번호의 고유 개수.
- **P2**: 파일 번호가 0부터 누락 없이 연속적이어야 함.
- **P3**: 전체 파일 수 == Σ(1 + N) (N은 '외 N건'의 수).
- **P4**: 모든 증빙 행이 **M4 규칙(기준파일명 일치)**을 통과해야 함.
- **P5**: 데이터 행 수, 대기중 행 수, 증빙 없는 대기중 행 수 산출.

### 단계 2: 증빙 매칭 (Matching Rules)
- **M1**: 합계 행(`계`)은 제외한다.
- **M2**: `수료증빙파일` 빈칸 $\to$ "증빙없음(제외)" 처리.
- **M3 (Key)**: 증빙 있는 행에 대해 0부터 순차적으로 번호 $k$를 부여. 폴더 내 `k_`로 시작하는 모든 파일이 해당 행의 증빙이다.
- **M4 (Cross-check)**: 엑셀의 `수료증빙파일`에서 ' 외 N건'을 제외한 기준파일명과 정확히 일치하는 파일이 $k\_$ 파일 중 딱 1개 있어야 하며, 총 파일 수는 $1+N$개여야 한다.
- **M5**: 파일명만으로 찾지 말고 반드시 번호(M3)를 1차 키로 사용한다.
- **M6**: 엑셀 원본 순서를 유지한다.

### 단계 3: 데이터 추출 (Extraction)
- **PDF**: 텍스트 추출 우선 $\to$ 빈약할 경우 Vision 판독(스캔본).
- **XLSX**: 셀 텍스트 추출 $\to$ 명단 내 성명/교번 존재 여부 확인.
- **HWPX**: 내부 XML 텍스트 추출.
- **기타**: 판독 불가 시 "수동 확인(판독 불가)" 처리.

### 단계 4: 항목 대조 및 판정 (Verification)
다음 6개 항목이 모두 적합해야 `승인추천`한다. **대조 시 성명, 기관, 과정명은 모든 공백 및 특수문자를 제거하고 알파벳, 숫자, 한글만 남긴 정규화 상태에서 비교하며, 과정명은 증빙 내 부분 일치(Containment)를 허용한다.**

1. **성명**: 일치 (공백 및 특수문자 무시, 스캔본의 한두 글자 오인식은 허용).
2. **기관**: '서울과학기술대학교'와 일치 (공백 및 특수문자 무시).
3. **과정명**: 핵심 키워드 일치. **목록 과정명 앞뒤의 분류 태그(예: `(기획력)`, `[직무]`)를 제거한 '핵심 과정명'을 추출하여 증빙 내 포함 여부를 판단한다.** (기수, 특수문자, 부가어, 띄어쓰기, PDF 줄바꿈 무시).
4. **시간**: $\\text{증빙 시간} \\ge \\max(\\text{실적시간}, \\text{인정시간})$ (분 단위 환산 비교).
5. **문서 형식**: 수료증, 이수증 등 공식 증빙 (안내문, 영수증 불가).
6. **발급 주체**: 기관명, 직인, 서명 확인.

**불일치 보고**: 증빙 파일은 찾았으나 내용이 불일치하는 경우, 단순히 '미발견'이라 하지 않고 **증빙서류에서 추출한 실제 값(과정명 등)을 사유란에 명시하여 대조 가능하게 출력**한다.

**확신도 설정:**
- **High**: 모든 항목 명확히 일치.
- **Medium**: 승인 추천이나 일부 모호함(오인식, 부제목 차이 등) 존재.
- **Low**: 1개 이상 불일치 또는 핵심 항목 불확실.

### 단계 5: 결과 보고 (Reporting)
1. **HTML 리포트**: KORUS 값 vs 증빙 값 나란히 표시, 항목별 일치 여부, 확신도, 사유.
2. **결과 엑셀**: 판정, 확신도, 사유, 증빙파일명, 체크대상(Y/N) 컬럼 추가.
3. **체크 대상 목록**: `승인추천 AND 확신도 >= 임계값`인 순번만 오름차순 나열.
4. **정합성 요약**: $\text{대기중 N건} = \text{승인추천} + \text{검토필요} + \text{증빙없음} + \text{수동확인}$.

## ⚠️ 예외 처리
- 증빙 시간이 더 큰 경우 $\to$ 정상 (사유에 적지 않음).
- 엑셀 시간 칸 비어 있음 $\to$ 증빙에 시간 있으면 적합, 사유에 "엑셀 시간 확인 불가" 기록.
- 증빙에 시간 표기 없음 $\to$ "수동 확인(시간 판단 불가)".
- 동일 파일명이 여러 행에 존재 $\to$ 번호로 구분하여 처리.
